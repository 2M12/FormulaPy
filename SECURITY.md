# 🔒 FormulaPy Security Policy

> The author reserves the right to make changes to this text.

This document describes the support status of various **FormulaPy** versions in terms of security updates and the procedure for reporting vulnerabilities.

## ❗ Version Support Status

| Version | Support Status |
|---------|----------------|
| v1.0.0 | Active support |

## 🔑 Status Definitions

* **Active support** — all security updates and vulnerability fixes are released for this version. Recommended for use.
* **Limited support** — fixes are released only for critical vulnerabilities (CVSS ≥ 7.0). New features or non-critical bug fixes are not added. Users are advised to upgrade to the latest version.
* **Support ended** — security updates are no longer released for this version. Use is not recommended. Upgrade to a supported version as soon as possible.

> [!CAUTION]
>
> ## 📬 Reporting Vulnerabilities
>
> If you discover a vulnerability in FormulaPy, please:
>
> 1. **Do not disclose information publicly** until a fix is released.
> 2. Use [GitHub Security Advisories](https://github.com/2M12/FormulaPy/security/advisories/new).
>
> In your report, include:
> * Type of vulnerability
> * Steps to reproduce
> * Affected version
> * Potential impact
>
> After the fix, you will be mentioned in the acknowledgments (optional).

---

## ☝ Recommendations for Users

For maximum security, use the latest version of the utility from the [Releases](https://github.com/2M12/FormulaPy/releases) section.

Older versions may contain unresolved vulnerabilities and do not provide full functionality.
